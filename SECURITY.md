# Security Policy

EntraShield is a defensive security audit toolkit. Please use it only in environments where you have authorization.

## Supported Versions

Pre-1.0 releases are under active development. Security fixes are applied to the latest release branch.

## Reporting a Vulnerability

If you find a security issue in EntraShield:

1. Do not open a public issue with sensitive details.
2. Create a private advisory if available, or contact the maintainer privately.
3. Include reproduction steps, affected version, and impact.
4. Do not include real tenant secrets, tokens, reports, or customer data.

## Data Handling

- Do not commit real tenant reports.
- Do not commit access tokens or exported Graph data.
- Sanitize screenshots before sharing.
- Use demo mode for public examples.
