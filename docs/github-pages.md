# GitHub Pages Demo

EntraShield includes a GitHub Pages-ready demo under the `docs` folder.

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Go to **Pages**.
4. Under **Build and deployment**, choose:

```text
Source: Deploy from a branch
Branch: main
Folder: /docs
```

5. Save.

After a few minutes, GitHub provides a URL like:

```text
https://YOUR-USERNAME.github.io/EntraShield-M365-Security-Audit/
```

## Demo files

```text
docs/index.html
docs/demo-report.html
```

## Important

Only sanitized demo content should be published via GitHub Pages. Do not publish real tenant reports.
