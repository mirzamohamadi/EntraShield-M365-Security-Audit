# Remediation: Migrate Away From SMS MFA

1. Identify users with SMS or voice registered.
2. Prioritize privileged users first.
3. Enable stronger methods such as FIDO2, passkeys, Windows Hello for Business, or Microsoft Authenticator number matching.
4. Communicate migration timeline.
5. Disable SMS and voice for admin accounts.
6. Remove SMS fallback for broader user populations after adoption.

Reference: https://pages.nist.gov/800-63-4/sp800-63b.html
